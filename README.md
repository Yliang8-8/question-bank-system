# 在线题库自动组卷系统

面向工科学生的在线题库、自动组卷、考试与成绩分析系统。教师可以管理题库、创建班级、发布考试；学生可以在线答题、查看成绩和错题本，并获得个人能力分析。

## 技术栈

- 后端：Python + Flask
- 数据库：SQLite
- 前端：HTML + CSS + JavaScript + Jinja2
- 试卷导出：python-docx、reportlab
- Excel 处理：openpyxl

## 当前功能

### 账号与权限

- 教师、学生登录和注册
- 教师端与学生端角色权限区分
- 修改用户名和密码
- 学生只能参加考试，教师可管理题库、班级、试卷和成绩

### 题库管理

- 新增、编辑、删除、搜索、筛选题目
- 支持单选题、多选题、判断题、填空题
- 支持科目、章节、难度、选项、答案和解析
- 内置计算机基础、高等数学、英语题库
- 支持 CSV 和 Excel 批量导入题目
- 可下载 CSV 模板和 Excel 模板
- 导入时自动跳过重复题目，并显示错误行

### 班级系统

- 教师创建、编辑、删除班级
- 教师添加学生到班级
- 支持输入学生账号或姓名添加学生
- 支持 CSV/Excel 批量导入学生，格式为：姓名、账号
- 一个学生只属于一个班级
- 一份试卷可以发布给多个班级
- 学生概览页显示所在班级名称
- 试卷管理页可按班级查看完成情况，如 33/40

### 自动组卷

- 按科目、章节、题型、难度抽题
- 支持题型数量、难度数量、每道题分值设置
- 支持考试时长设置
- 支持限做次数设置
- 支持试卷预览和人工更换题目
- 生成新试卷时必须选择发布班级

### 在线考试

- 考试倒计时
- 答案本地暂存，刷新页面不丢失
- 答题进度实时显示
- 右侧答题卡，支持题目标记和跳转
- 到时自动提交、提交前二次确认
- 同一学生同一试卷按限做次数控制
- 学生端显示可做次数
- 可做次数大于等于 2 时显示“快速重练”
- 限做 1 次时开始考试提示“该卷限做1次”

### 成绩与错题本

- 自动评分
- 成绩记录、筛选和统计
- 正确率分析
- 分数分布图
- 历次考试能力波动折线图，含班级平均分参照线
- 个人能力雷达图，按科目展示章节掌握度
- 分析页顶部科目筛选统一控制正确率、雷达图和趋势图
- 错题本
- 错题本支持按关键词、科目、难度、题型筛选
- 成绩分析支持按班级筛选

### 其他功能

- 试卷导出 Word/PDF
- 同一 Wi-Fi 下手机访问
- 校园背景登录页和系统内页面美化
- 玻璃磨砂、数字动画、新增题数角标等界面交互

## 批量导入格式

### 题目导入

CSV 或 Excel 第一行使用以下字段：

```text
科目,章节,题型,难度,题目内容,选项,答案,解析
```

示例：

```text
计算机基础,Python基础,单选题,简单,Python 中用于定义函数的关键字是什么？,A. def|B. class|C. import|D. return,A,def 用于定义函数。
```

选择题选项使用竖线 `|` 或分号分隔。

### 学生导入

CSV 或 Excel 第一行使用以下字段：

```text
姓名,账号
```

示例：

```text
张三,20240001
```

## 班级使用流程

1. 教师登录。
2. 进入“班级”页面，新建班级。
3. 添加学生或批量导入学生。
4. 进入“自动组卷”，设置题目、分值、考试时长和限做次数。
5. 选择要发布的班级，预览并生成试卷。
6. 学生登录后查看试卷并开始考试。

## 演示建议

1. 教师登录，进入题库展示题目和筛选。
2. 教师进入“批量导入”，下载模板并说明 CSV/Excel 导入。
3. 教师进入“班级”，创建班级并添加学生。
4. 教师进入“自动组卷”，设置组卷规则、考试时长、限做次数和发布班级。
5. 预览试卷并展示更换题目功能。
6. 学生登录，展示试卷列表只显示本班试卷、可做次数和快速重练。
7. 学生完成考试，查看成绩和错题本。
8. 学生进入分析页，展示顶部科目筛选联动正确率、雷达图和趋势图。
9. 教师进入成绩和分析页面，展示按班级筛选、班级完成情况和学生学情详情。

## 说明

- 历史试卷如果未设置发布班级，默认对所有学生可见。
- 新试卷必须选择至少一个发布班级。
- 数据库结构会在系统启动时自动迁移，无需手动修改。
