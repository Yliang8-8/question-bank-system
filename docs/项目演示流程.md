# 在线题库自动组卷系统演示流程

## 演示前准备

1. 打开项目目录：`C:\Users\Lenovo\Desktop\在线题库自动组卷系统\question-bank-system`
2. 在该目录运行：`python app.py`
3. 电脑浏览器打开：`http://127.0.0.1:5000`
4. 同一 Wi-Fi 手机访问时，使用电脑局域网 IP，例如：`http://192.168.1.10:5000`

## 教师端演示

1. 使用教师账号登录：`teacher / teacher123`
2. 进入“题库”，展示科目、题型、难度、章节、选项和答案维护。
3. 进入“批量导入题目”，下载 CSV 或 Excel 模板，说明批量建库。
4. 进入“班级”，新建班级，添加学生或批量导入学生。
5. 进入“自动组卷”，设置科目、章节、题型、难度、分值、考试时长和限做次数。
6. 选择发布班级，点击“预览试卷”，展示左侧预览和右侧同类型候选题更换。
7. 点击“生成试卷”，进入教师试卷详情，展示答案和解析。
8. 进入“试卷管理”，选择班级，展示完成情况如 33/40。
9. 进入“成绩”和“分析”，展示班级筛选、学生学情列表和个人学情详情。
10. 在试卷详情中演示 Word/PDF 导出。

## 学生端演示

1. 使用学生账号登录：`student / student123`
2. 进入“试卷”，展示学生只能开始考试，不能提前查看试题详情。
3. 展示可做次数和“快速重练”功能。
4. 开始考试，展示单选题、多选题、判断题、填空题对应作答控件和右侧答题卡。
5. 提交试卷后进入结果页，展示分数、答案、解析和错题。
6. 进入“成绩分析”，展示顶部科目筛选联动正确率、能力雷达图和成绩趋势图。
7. 进入“错题本”，展示学生错题复盘。

## 答辩说明重点

1. 项目解决教师组卷效率低、试卷难度控制弱、学生错题复盘不方便的问题。
2. 核心闭环：题库建设 -> 班级管理 -> 自动组卷 -> 人工换题 -> 在线考试 -> 自动评分 -> 错题复盘 -> 成绩分析。
3. 教师端和学生端权限分离，学生未提交考试前不能查看答案。
4. 一份试卷可发布给多个班级，并按班级查看完成情况。
5. 学生端提供可做次数、快速重练和限做提示，兼顾练习与考试场景。
6. 成绩分析支持班级筛选、个人能力画像和成绩趋势，体现数据分析能力。
7. 系统支持本机运行，也支持同一 Wi-Fi 下手机访问，便于课堂或小范围实践演示。
